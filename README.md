# 🏛️ Minimalist Dark & Dollar-Style Institutional Portfolio

موقع بورتفوليو شخصي ومؤسسي ذو طابع عالمي وعصري **(Minimalist Dark / Dollar Style)**، مصمم خصيصاً لاستعراض الأعمال والأنشطة الإعلامية، الوثائقية، وحقوق الإنسان للجهات الدولية والسفارات.

---

## 🌟 الميزات الرئيسية (Key Features)

- **🎨 تصميم عصري فاخر (Luxury Dark Aesthetics):** يعتمد على أسلوب التباين العالي (High Contrast) بألوان داكنة راقية ولمسات ذهبية مؤسسية (`#c5a880`).
- **⚡ فلترة تفاعلية لحظية (Interactive Portfolio Grid):** تصفية مرئيات ومعرض الأعمال أوتوماتيكياً بدون إعادة تحميل الصفحة بفضل JavaScript.
- **📱 تجاوب كامل (100% Responsive):** تجربة تصفح سلسة ومثالية على كافة الشاشات (الهواتف الذكية، التابلت، أجهزة اللابتوب).
- **⏱️ خط زمني للخبرات (Interactive Timeline):** عرض الشهادات، الورش، والمشاركات الدولية بأسلوب منظّم.
- **✉️ نموذج تواصل متكامل (Working Contact UI):** معالج تفاعلي لاستقبال الاستفسارات والطلبات.
- **🚀 أداء فائق السرعة:** كود نظيف (Clean Code) مبني باستخدام Pure HTML5/CSS3/Vanilla JS بدون استخدام أي مكتبات ثقيلة خارجية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5:** بناء الهيكلية ودعم محركات البحث (Semantic HTML).
- **CSS3:** مخصص بأسلوب Flexbox & CSS Grid مع متغيرات ألوان (CSS Variables) وتأثيرات Glassmorphism.
- **Vanilla JavaScript (ES6+):** للتحكم في فلترة الأعمال وتفاعل النموذج.
- **FontAwesome & Google Fonts:** أيقونات وتطبيقات الخطوط (Tajawal & Plus Jakarta Sans).
